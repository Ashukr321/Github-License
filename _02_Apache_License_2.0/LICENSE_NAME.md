# Apache License 2.0

## 📜 Overview

The **Apache License 2.0** is a permissive open-source license created by the **Apache Software Foundation (ASF)**. It is one of the most popular licenses for enterprise-grade open-source projects. Its key differentiator from the MIT License is the **explicit patent grant**, providing stronger legal protection for both contributors and users.

## 🔑 Key Characteristics

- **Permissive**: Similar to MIT but with more legal detail
- **Patent Grant**: Explicitly grants patent rights to users
- **Patent Retaliation**: If you sue a contributor for patent infringement, your license terminates
- **NOTICE Preservation**: Requires preserving attribution notices
- **Change Documentation**: Requires noting significant modifications
- **No Copyleft**: Derivative works can be proprietary
- **Enterprise-Ready**: Designed for large-scale corporate adoption

---

## 🛡️ Patent Grant — The Key Differentiator

The Apache 2.0's **explicit patent grant** means:

```
When a contributor submits code, they automatically grant users a
royalty-free, worldwide, non-exclusive patent license to use that
contribution. This protects users from patent lawsuits by contributors.
```

### Patent Retaliation Clause
```
If you initiate a patent lawsuit alleging that the software infringes
your patents, your license (including the patent grant) terminates
automatically.
```

> 🔒 This provides a **defensive shield** against patent trolls and aggressive litigation.

## 📊 Comparison: Apache 2.0 vs MIT

| Feature              | Apache 2.0      | MIT License   |
| -------------------- | --------------- | ------------- |
| Permissive           | ✅ Yes          | ✅ Yes        |
| Patent Grant         | ✅ Yes          | ❌ No         |
| Copyleft             | ❌ No           | ❌ No         |
| Simplicity           | Moderate        | Very Simple   |
| GPL Compatible       | ✅ (with GPLv3) | ✅ Yes        |
| NOTICE File Required | ✅ Yes          | ❌ No         |
| State Changes        | ✅ Required     | ❌ Not needed |
