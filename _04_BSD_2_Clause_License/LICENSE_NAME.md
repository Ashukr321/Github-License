# BSD 2-Clause "Simplified" License

## 📜 Overview

The **BSD 2-Clause License** (also known as the **"Simplified BSD License"** or **"FreeBSD License"**) is one of the simplest and most permissive open-source licenses. It originated from the **University of California, Berkeley** (BSD = Berkeley Software Distribution) and is essentially an even more minimal version of the MIT License.

## 🔑 Key Characteristics

- **Ultra-Permissive**: Even simpler than MIT
- **Two Conditions Only**: Retain copyright in source and binary distributions
- **No Copyleft**: Derivatives can be proprietary
- **No Patent Grant**: Unlike Apache 2.0
- **No Endorsement Clause**: Unlike BSD 3-Clause
- **GPL Compatible**: Can be combined with GPL code

---

## 📊 BSD 2-Clause vs BSD 3-Clause vs MIT

| Feature                | BSD 2-Clause | BSD 3-Clause | MIT     |
| ---------------------- | ------------ | ------------ | ------- |
| Permissive             | ✅ Yes       | ✅ Yes       | ✅ Yes  |
| Number of Clauses      | 2            | 3            | ~2      |
| Non-Endorsement Clause | ❌ No        | ✅ Yes       | ❌ No   |
| Simplicity             | Very Simple  | Simple       | Simple  |
| GPL Compatible         | ✅ Yes       | ✅ Yes       | ✅ Yes  |
