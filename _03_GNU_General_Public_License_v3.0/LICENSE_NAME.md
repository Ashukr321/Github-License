# GNU General Public License v3.0 (GPL-3.0)

## 📜 Overview

The **GNU General Public License v3.0 (GPL-3.0)** is a **strong copyleft** license created by the **Free Software Foundation (FSF)**, authored by **Richard Stallman**. It is the most widely used copyleft license and is designed to guarantee users' freedom to share and modify all versions of a program.

The core principle: **If you distribute software that includes GPL code, you must also release your source code under the GPL.**

---

## 📝 Key License Provisions

The GPL v3.0 was released on **June 29, 2007**, and includes several improvements over v2.0:

1. **Freedom to use** the software for any purpose
2. **Freedom to study** how the software works and modify it
3. **Freedom to distribute** copies of the software
4. **Freedom to distribute modified versions** to benefit the community
5. **Anti-Tivoization** protection (preventing hardware restrictions)
6. **Patent grant** for contributors
7. **Compatibility** improvements with other licenses

> 📖 Full text: [GPL v3.0](https://www.gnu.org/licenses/gpl-3.0.html)

## 🔑 Key Characteristics

- **Strong Copyleft**: All derivative works must be GPL-3.0
- **Viral Effect**: GPL "infects" any code linked with it
- **Source Code Disclosure**: Must share source code when distributing
- **Anti-Tivoization**: Prevents hardware from blocking modified software
- **Patent Grant**: Contributors grant patent rights to users
- **Compatible with AGPL**: Can be combined with AGPL-3.0 code
- **Not compatible with GPLv2**: Cannot mix with GPL-2.0 code directly

---

## 🛡️ The Copyleft Mechanism

```
How Copyleft Works:

1. You use GPL-3.0 code in your project
2. Your entire project becomes GPL-3.0
3. Anyone who receives your software also gets:
   - The source code
   - The right to modify and redistribute
   - All the same freedoms you had

This creates a "freedom chain" — ensuring the software
and all its derivatives remain free forever.
```

### Anti-Tivoization (New in v3)
```
The Problem (v2):
  TiVo used GPL-2.0 Linux kernel but locked the hardware
  so users couldn't run modified versions.

The Solution (v3):
  GPL-3.0 requires that if you distribute GPL software on
  hardware, users must be able to install modified versions.
  "If you distribute GPL code in a device, the device must
  accept modified versions of that code."
```

## 🧠 Developer's Perspective

> "If you believe that all software built on free software should remain free — GPL v3.0 embodies that philosophy. It's the **'freedom must be preserved'** license."

GPL v3.0 is for developers who believe:
- Open source should **stay** open source
- Companies shouldn't be able to take your work and make it proprietary
- Users should always have the freedom to modify the software they use

---

## ⚠️ Important Notes

### Private Use Exception
If you use GPL software **privately** (not distributed), you have NO obligations:
- Internal company tools? **No source disclosure required**
- Personal modifications? **No sharing required**
- Only **distribution** triggers copyleft obligations

### SaaS Loophole
GPL does NOT cover software accessed over a network (SaaS). If you modify GPL software and provide it as a web service without distributing it, you don't need to share your source code. For that, use **AGPL-3.0**.
