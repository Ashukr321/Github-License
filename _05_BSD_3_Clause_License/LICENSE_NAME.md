# BSD 3-Clause "New" or "Revised" License

## 📜 Overview

The **BSD 3-Clause License** (also known as the **"New BSD License"** or **"Revised BSD License"**) adds one important clause to the BSD 2-Clause License: a **non-endorsement clause** that prevents using the project's name or contributors' names to endorse derived products without permission.

## 🔑 The Non-Endorsement Clause (Clause 3)

The key addition over BSD 2-Clause:

```
"Neither the name of the copyright holder nor the names of its
contributors may be used to endorse or promote products derived
from this software without specific prior written permission."
```

### What this means:
- ❌ You CANNOT say "This product is endorsed by [Original Author]"
- ❌ You CANNOT use the original project's name to promote your fork
- ❌ You CANNOT imply the original authors approve of your modifications
- ✅ You CAN still mention you used the original software (attribution)

## 📊 BSD 3-Clause vs BSD 2-Clause

| Feature                | BSD 2-Clause | BSD 3-Clause |
| ---------------------- | ------------ | ------------ |
| Copyright Notice       | ✅ Required  | ✅ Required  |
| Binary Reproduction    | ✅ Required  | ✅ Required  |
| Non-Endorsement Clause | ❌ No        | ✅ Yes       |
| Name Protection        | ❌ No        | ✅ Yes       |
| Complexity             | Simpler      | Slightly More|
