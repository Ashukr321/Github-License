# Boost Software License 1.0

## 📜 Overview

The **Boost Software License 1.0 (BSL-1.0)** is a simple, permissive open-source license originally created for the **Boost C++ Libraries**. It is notable for being one of the **most permissive licenses** available — even more so than MIT in some respects, because it does **not require attribution in binary distributions**.

## 🔑 Key Characteristics

- **Ultra-Permissive**: Easier than MIT for binary distribution
- **No Binary Attribution**: Don't need copyright notice in compiled software
- **Source Attribution**: Only required when sharing source code
- **C++ Ecosystem Standard**: The standard license in the Boost/C++ world
- **OSI Approved**: Recognized by the Open Source Initiative
- **GPL Compatible**: Can be used with GPL code

## 🧠 Developer's Perspective

> "Boost License is for when you want MIT-level freedom but don't even want to burden binary distributors with attribution. It's the **'just use it'** license."
